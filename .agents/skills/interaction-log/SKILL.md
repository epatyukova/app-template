# Interaction Log

Use this skill only when the user asks to save or update an interaction summary.

Write `docs/interactions/YYYY-MM-DD-short-topic.md`, or update the existing file for the same continuing topic. Include:

- the user's goal in paraphrased form;
- decisions and their rationale;
- actual files or behaviour changed;
- checks performed and their outcomes;
- unresolved limitations or follow-up work.

Do not copy full prompts, responses, command output, private data, credentials, tokens, or unnecessary personal information. Redact sensitive values and ask before preserving anything that may be confidential. Do not create a log merely because an agent answered a question.
